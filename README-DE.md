## ⚡ Überblick

**MiroFish** ist eine KI-Vorhersage-Engine der nächsten Generation, angetrieben durch Multi-Agent-Technologie. Durch die Extraktion von Ausgangsinformationen aus der realen Welt (wie aktuelle Nachrichten, Politikentwürfe oder Finanzsignale) wird automatisch eine hochpräzise parallele digitale Welt konstruiert. Innerhalb dieses Raums interagieren Tausende intelligenter Agenten mit eigenständigen Persönlichkeiten, Langzeitgedächtnis und Verhaltenslogik frei miteinander und durchlaufen eine soziale Evolution. Sie können dynamisch Variablen aus einer „Gottesperspektive" einfügen, um zukünftige Entwicklungen präzise abzuleiten — **proben Sie die Zukunft in einer digitalen Sandbox und gewinnen Sie Entscheidungen nach unzähligen Simulationen**.

> Sie müssen lediglich: Ausgangsmaterialien hochladen (Datenanalyseberichte oder interessante Romangeschichten) und Ihre Vorhersageanforderungen in natürlicher Sprache beschreiben</br>
> MiroFish liefert Ihnen: Einen detaillierten Vorhersagebericht und eine tiefgehend interaktive, hochpräzise digitale Welt

### Unsere Vision

MiroFish widmet sich der Erschaffung eines Schwarmintelligenz-Spiegels, der die Realität abbildet. Indem wir die kollektive Emergenz erfassen, die durch individuelle Interaktionen ausgelöst wird, durchbrechen wir die Grenzen herkömmlicher Vorhersagen:

- **Auf der Makroebene**: Wir sind ein Probelabor für Entscheidungsträger, in dem Richtlinien und Öffentlichkeitsarbeit ohne jedes Risiko getestet werden können
- **Auf der Mikroebene**: Wir sind eine kreative Sandbox für einzelne Nutzer — ob Sie Romanenden ableiten oder fantasievolle Szenarien erkunden, alles kann unterhaltsam, spielerisch und zugänglich sein

Von seriösen Vorhersagen bis hin zu spielerischen Simulationen lassen wir jedes „Was wäre wenn" sein Ergebnis sehen und machen es möglich, alles vorherzusagen.

## 📖 Geschichtenmodus (Neu!)

MiroFish unterstützt jetzt den **Geschichtenmodus** — zusätzlich zur Vorhersage der Zukunft können Sie damit **kreative Erzählungen** aus Ihren Ausgangsmaterialien generieren.

### Funktionsweise

Wählen Sie auf der Startseite zwischen zwei Modi:

| Modus | Beschreibung |
|-------|-------------|
| **Vorhersage** (Standard) | Analysiert Ausgangsdaten und erstellt einen analytischen Vorhersagebericht |
| **Geschichte** | Nutzt dieselbe Simulations-Engine, generiert jedoch kreative Fiktion — Prosa im Romanstil oder im Drehbuchformat |

### Ausgabeformate für Geschichten

- **Roman**: Reichhaltige Prosa mit lebhaften Szenenbeschreibungen, authentischen Charakterdialogen, inneren Gedanken und einem Erzählbogen
- **Drehbuch**: Professionelles Drehbuchformat mit INT./EXT.-Szenenüberschriften, Charakternamen in GROSSBUCHSTABEN, Regieanweisungen und visueller Erzählung

### Beispielanwendung

Laden Sie ein Weltenbau-Dokument hoch (z. B. ein Harry-Potter-Universum mit eigenen Charakteren), wählen Sie den Modus **Geschichte** und geben Sie eine Prämisse ein wie:

> *„Schreibe eine Geschichte aus der Perspektive von Derek Thorne — einem muggelstämmigen Kind, das eine Waffe nach Hogwarts geschmuggelt hat"*

MiroFish simuliert Charakterinteraktionen und generiert anschließend eine Erzählung mit mehreren Kapiteln, in der die Charaktere basierend auf ihren Persönlichkeiten und Beziehungen eigenständig handeln.

### Was sich im Geschichtenmodus ändert

| Schritt | Vorhersagemodus | Geschichtenmodus |
|---------|----------------|-----------------|
| Schritt 1 | Graph-Aufbau | Weltenaufbau |
| Schritt 2 | Umgebungseinrichtung | Charaktereinrichtung |
| Schritt 3 | Simulation starten | Erzählung ausführen |
| Schritt 4 | Berichterstellung | Geschichtenerstellung |
| Schritt 5 | Tiefe Interaktion | Charakter-Chat |

Die Simulations-Agenten verhalten sich als **fiktive Charaktere** anstatt als Social-Media-Nutzer, und der ReportAgent verfasst **erzählerische Kapitel** anstelle analytischer Abschnitte.

## 🔄 Arbeitsablauf

1. **Graph-Aufbau**: Extraktion der Ausgangsdaten & Einspeisung von individuellem/kollektivem Gedächtnis & GraphRAG-Konstruktion
2. **Umgebungseinrichtung**: Extraktion von Entitätsbeziehungen & Persona-Generierung & Einspeisung der Agent-Konfiguration
3. **Simulation**: Parallele Simulation auf zwei Plattformen & automatisches Parsen der Vorhersageanforderungen & dynamische zeitliche Gedächtnisaktualisierungen
4. **Berichterstellung**: ReportAgent mit umfangreichem Toolset für tiefgehende Interaktion mit der Nachsimulationsumgebung
5. **Tiefe Interaktion**: Chatten Sie mit jedem Agent in der simulierten Welt & Interagieren Sie mit dem ReportAgent

## 🚀 Schnellstart

### Option 1: Quellcode-Bereitstellung (Empfohlen)

#### Voraussetzungen

| Werkzeug | Version | Beschreibung | Installation prüfen |
|----------|---------|-------------|---------------------|
| **Node.js** | 18+ | Frontend-Laufzeitumgebung, enthält npm | `node -v` |
| **Python** | ≥3.11, ≤3.12 | Backend-Laufzeitumgebung | `python --version` |
| **uv** | Neueste | Python-Paketmanager | `uv --version` |

#### 1. Umgebungsvariablen konfigurieren

```bash
# Beispielkonfigurationsdatei kopieren
cp .env.example .env

# Die .env-Datei bearbeiten und die erforderlichen API-Schlüssel eintragen
```

**Erforderliche Umgebungsvariablen:**

```env
# LLM API-Konfiguration (unterstützt jede LLM API im OpenAI-SDK-Format)
# Empfohlen: Alibaba Qwen-plus-Modell über die Bailian-Plattform: https://bailian.console.aliyun.com/
# Hoher Verbrauch, versuchen Sie zunächst Simulationen mit weniger als 40 Runden
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_NAME=qwen-plus

# Zep Cloud-Konfiguration
# Das kostenlose monatliche Kontingent reicht für einfache Nutzung aus: https://app.getzep.com/
ZEP_API_KEY=your_zep_api_key
```

#### 2. Abhängigkeiten installieren

```bash
# Ein-Klick-Installation aller Abhängigkeiten (Root + Frontend + Backend)
npm run setup:all
```

Oder schrittweise installieren:

```bash
# Node-Abhängigkeiten installieren (Root + Frontend)
npm run setup

# Python-Abhängigkeiten installieren (Backend, erstellt automatisch eine virtuelle Umgebung)
npm run setup:backend
```

#### 3. Dienste starten

```bash
# Frontend und Backend starten (vom Projektstammverzeichnis ausführen)
npm run dev
```

**Dienst-URLs:**
- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:5001`

**Einzeln starten:**

```bash
npm run backend   # Nur Backend starten
npm run frontend  # Nur Frontend starten
```

### Option 2: Docker-Bereitstellung

```bash
# 1. Umgebungsvariablen konfigurieren (wie bei der Quellcode-Bereitstellung)
cp .env.example .env

# 2. Image herunterladen und starten
docker compose up -d
```

Liest standardmäßig `.env` aus dem Stammverzeichnis, Port-Zuordnung `3000 (Frontend) / 5001 (Backend)`

> Eine Mirror-Adresse für schnelleres Herunterladen ist als Kommentar in `docker-compose.yml` hinterlegt, ersetzen Sie diese bei Bedarf.
