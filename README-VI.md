## ⚡ Tổng Quan

**MiroFish** là một công cụ dự đoán AI thế hệ mới được hỗ trợ bởi công nghệ đa Agent. Bằng cách trích xuất thông tin hạt giống từ thế giới thực (như tin tức nóng hổi, dự thảo chính sách, hoặc tín hiệu tài chính), hệ thống tự động xây dựng một thế giới kỹ thuật số song song có độ trung thực cao. Trong không gian này, hàng nghìn Agent thông minh với tính cách độc lập, trí nhớ dài hạn và logic hành vi tự do tương tác và trải qua quá trình tiến hóa xã hội. Bạn có thể đưa vào các biến số một cách linh hoạt từ "góc nhìn toàn năng" để suy luận chính xác các quỹ đạo tương lai — **diễn tập tương lai trong hộp cát kỹ thuật số, và chiến thắng các quyết định sau vô số lần mô phỏng**.

> Bạn chỉ cần: Tải lên tài liệu hạt giống (báo cáo phân tích dữ liệu hoặc những câu chuyện tiểu thuyết thú vị) và mô tả yêu cầu dự đoán của bạn bằng ngôn ngữ tự nhiên</br>
> MiroFish sẽ trả về: Một báo cáo dự đoán chi tiết và một thế giới kỹ thuật số có độ trung thực cao với khả năng tương tác sâu

### Tầm Nhìn Của Chúng Tôi

MiroFish cam kết tạo ra một tấm gương trí tuệ bầy đàn phản ánh thực tế. Bằng cách nắm bắt sự nổi trội tập thể được kích hoạt từ các tương tác cá nhân, chúng tôi phá vỡ giới hạn của dự đoán truyền thống:

- **Ở Tầm Vĩ Mô**: Chúng tôi là phòng thí nghiệm diễn tập cho các nhà hoạch định, cho phép thử nghiệm chính sách và quan hệ công chúng với rủi ro bằng không
- **Ở Tầm Vi Mô**: Chúng tôi là hộp cát sáng tạo cho người dùng cá nhân — dù là suy luận kết thúc tiểu thuyết hay khám phá các kịch bản tưởng tượng, mọi thứ đều có thể thú vị, vui nhộn và dễ tiếp cận

Từ dự đoán nghiêm túc đến mô phỏng vui nhộn, chúng tôi để mọi câu hỏi "nếu như" đều nhìn thấy kết quả, biến việc dự đoán mọi thứ trở nên khả thi.

## 📖 Chế Độ Truyện (Mới!)

MiroFish hiện hỗ trợ **Chế Độ Truyện** — ngoài việc dự đoán tương lai, bạn có thể sử dụng nó để **tạo ra các câu chuyện sáng tạo** từ tài liệu hạt giống của bạn.

### Cách Hoạt Động

Trên trang chủ, chọn giữa hai chế độ:

| Chế độ | Chức năng |
|--------|-----------|
| **Dự đoán** (mặc định) | Phân tích dữ liệu hạt giống và tạo báo cáo dự đoán phân tích |
| **Truyện** | Sử dụng cùng một công cụ mô phỏng nhưng tạo ra tiểu thuyết sáng tạo — văn xuôi phong cách tiểu thuyết hoặc định dạng kịch bản |

### Định Dạng Đầu Ra Truyện

- **Tiểu thuyết**: Văn xuôi phong phú với mô tả cảnh sinh động, đối thoại nhân vật chân thực, suy nghĩ nội tâm và cung kịch tự sự
- **Kịch bản**: Định dạng kịch bản chuyên nghiệp với tiêu đề cảnh NỘI/NGOẠI, tên nhân vật viết HOA, chỉ dẫn diễn xuất và kể chuyện bằng hình ảnh

### Ví Dụ Sử Dụng

Tải lên một tài liệu xây dựng thế giới (ví dụ: hạt giống vũ trụ Harry Potter với các nhân vật tùy chỉnh), chọn chế độ **Truyện**, và nhập một tiền đề như:

> *"Viết một câu chuyện từ góc nhìn của Derek Thorne — một đứa trẻ gốc muggle đã lén mang một khẩu súng vào Hogwarts"*

MiroFish sẽ mô phỏng các tương tác nhân vật, sau đó tạo ra một câu chuyện nhiều chương nơi các nhân vật hành động tự chủ dựa trên tính cách và mối quan hệ của họ.

### Những Gì Thay Đổi Trong Chế Độ Truyện

| Bước | Chế Độ Dự Đoán | Chế Độ Truyện |
|------|----------------|---------------|
| Bước 1 | Xây dựng đồ thị | Xây dựng thế giới |
| Bước 2 | Thiết lập môi trường | Thiết lập nhân vật |
| Bước 3 | Bắt đầu mô phỏng | Chạy tự sự |
| Bước 4 | Tạo báo cáo | Tạo truyện |
| Bước 5 | Tương tác sâu | Trò chuyện với nhân vật |

Các Agent mô phỏng hoạt động như **nhân vật hư cấu** thay vì người dùng mạng xã hội, và ReportAgent viết **các chương tự sự** thay vì các phần phân tích.

## 🔄 Quy Trình Hoạt Động

1. **Xây Dựng Đồ Thị**: Trích xuất hạt giống & Tiêm bộ nhớ cá nhân/tập thể & Xây dựng GraphRAG
2. **Thiết Lập Môi Trường**: Trích xuất quan hệ thực thể & Tạo nhân cách & Tiêm cấu hình Agent
3. **Mô Phỏng**: Mô phỏng song song đa nền tảng & Tự động phân tích yêu cầu dự đoán & Cập nhật bộ nhớ thời gian động
4. **Tạo Báo Cáo**: ReportAgent với bộ công cụ phong phú để tương tác sâu với môi trường hậu mô phỏng
5. **Tương Tác Sâu**: Trò chuyện với bất kỳ Agent nào trong thế giới mô phỏng & Tương tác với ReportAgent

## 🚀 Bắt Đầu Nhanh

### Tùy Chọn 1: Triển Khai Từ Mã Nguồn (Khuyến nghị)

#### Yêu Cầu Tiên Quyết

| Công cụ | Phiên bản | Mô tả | Kiểm tra cài đặt |
|---------|-----------|-------|-------------------|
| **Node.js** | 18+ | Môi trường chạy Frontend, bao gồm npm | `node -v` |
| **Python** | ≥3.11, ≤3.12 | Môi trường chạy Backend | `python --version` |
| **uv** | Mới nhất | Trình quản lý gói Python | `uv --version` |

#### 1. Cấu Hình Biến Môi Trường

```bash
# Sao chép tệp cấu hình mẫu
cp .env.example .env

# Chỉnh sửa tệp .env và điền các API key cần thiết
```

**Biến môi trường bắt buộc:**

```env
# LLM API Configuration (supports any LLM API with OpenAI SDK format)
# Recommended: Alibaba Qwen-plus model via Bailian Platform: https://bailian.console.aliyun.com/
# High consumption, try simulations with fewer than 40 rounds first
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_NAME=qwen-plus

# Zep Cloud Configuration
# Free monthly quota is sufficient for simple usage: https://app.getzep.com/
ZEP_API_KEY=your_zep_api_key
```

#### 2. Cài Đặt Phụ Thuộc

```bash
# Cài đặt tất cả phụ thuộc bằng một lệnh (root + frontend + backend)
npm run setup:all
```

Hoặc cài đặt từng bước:

```bash
# Cài đặt phụ thuộc Node (root + frontend)
npm run setup

# Cài đặt phụ thuộc Python (backend, tự động tạo môi trường ảo)
npm run setup:backend
```

#### 3. Khởi Động Dịch Vụ

```bash
# Khởi động cả frontend và backend (chạy từ thư mục gốc dự án)
npm run dev
```

**Địa chỉ dịch vụ:**
- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:5001`

**Khởi động riêng lẻ:**

```bash
npm run backend   # Chỉ khởi động backend
npm run frontend  # Chỉ khởi động frontend
```

### Tùy Chọn 2: Triển Khai Bằng Docker

```bash
# 1. Cấu hình biến môi trường (giống như triển khai từ mã nguồn)
cp .env.example .env

# 2. Tải image và khởi động
docker compose up -d
```

Mặc định đọc `.env` từ thư mục gốc, ánh xạ cổng `3000 (frontend) / 5001 (backend)`

> Địa chỉ mirror để tải nhanh hơn được cung cấp dưới dạng chú thích trong `docker-compose.yml`, thay thế nếu cần.
